# Task01 — MovieLens dataset

## Структура файлов

| Файл | Описание | Формат |
|------|----------|--------|
| `ratings.csv` | Оценки фильмов пользователями | `userId,movieId,rating,timestamp` |
| `movies.csv` | Список фильмов | `movieId,title,genres` |
| `tags.csv` | Теги, поставленные пользователями | `userId,movieId,tag,timestamp` |
| `users.txt` | Информация о пользователях | `userId::gender::age::occupation::zip` |
| `genres.txt` | Список жанров | одна строка — один жанр |
| `occupation.txt` | Список профессий | одна строка — одна профессия |
| `ratings_count.txt` | Мин./макс. userId и количество строк с ними | две строки: `<id> <count>` |
| `sqlite.txt` | Версия SQLite и режимы вывода | текст |

## Описание данных

- **ratings.csv** — основной файл с оценками. Первая строка — заголовок.
  - `userId` - идентификатор пользователя
  - `movieId` - идентификатор фильма
  - `rating` - оценка от 1 до 5
  - `timestamp` - время в формате Unix
- **movies.csv** - каталог фильмов с названиями и жанрами через `|`.
- **users.txt** - разделитель `::`, содержит пол, возраст, профессию и индекс пользователя.
- **ratings_count.txt** - результат анализа `ratings.csv`: строка 1 - минимальный userId и число его строк, строка 2 - максимальный userId и число его строк.
- **sqlite.txt** - информация об установленной версии SQLite и доступных режимах вывода `.mode`.

## Цель работы

Подготовка окружения для работы с СУБД SQLite: установка консольного клиента `sqlite3`, работа в интерактивном режиме, изучение режимов вывода данных.
